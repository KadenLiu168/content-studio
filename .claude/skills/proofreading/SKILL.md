# 三遍审校

## 第一遍：内容审

- 事实核查：所有数据、日期、版本号是否正确
- 逻辑检查：因果关系是否成立
- 结构检查：是否有遗漏的要点
- 数据和引文应有可核查来源；无法确认的事实标为待核实，不编造数据、经历或引文
- 检查标题和封面中的事实、效果与承诺是否有正文及相应证据支持；图片和素材来源是否明确，涉及授权时是否可用

## 第二遍：风格审

检查以下表达问题，仅在影响理解或不符合作者风格时修改：

1. 套话连篇 → 删除
2. 机械句式 → 按语义和阅读节奏调整，不强制口语化
3. 过度书面 → 在符合作者风格和平台需求时换用日常表达，保留准确的专业用语
4. 结构不利于理解 → 按读者问题和论证关系调整，保留清楚的列表、步骤和必要层次
5. 观点含糊 → 根据作者已明确的立场澄清，不自行添加观点
6. 细节缺失 → 补充有来源的事实或作者提供的细节；缺少依据时标为待补充

保留原意和必要的专业术语；不以 AI 检测分数作为审校保证。

## 第三遍：细节审

- 句子和段落长度：按内容、平台和阅读节奏调整，拆分影响理解的长句长段
- 加粗标记：仅突出必要的重点，不规定数量
- 引号：中文行文使用「」；代码、直接引文和平台格式要求按原有规范处理
- 破折号（——）：减少不必要的使用，不为满足数量而改变句意

## 审校结果

- 说明主要修改及仍待核实、补充或作者确认的问题，不将未实际查证的事实报告为已核实。
- 仍有支撑主要结论的关键事实待核实时，保留工作稿；形成发布稿须满足工作区 `AGENTS.md` 的发布条件。
