# 写作参考

存放跨平台可复用的写作资料、样稿、风格说明和创作规划。单篇内容的来源材料放在对应选题目录的 `sources.md` 中。

资料正文以中文为主，文件名使用英文，遵循根目录 `AGENTS.md`。

## 账号资料

- [进击的刘哥：账号资料](account-profile.md)：已确认的平台、读者、内容范围和商业目标，以及待补充事项。
- [写作样稿](writing-samples.md)：作者提供的参考链接、读取状态及待补充信息。

## 待评估能力

原规则中列出的以下 Skills 尚未实现，不作为当前可调用能力：

- `research`：结构化调研。
- `topic-gen`：选题生成。

有明确需求时，先评估现有能力是否足够，再决定是否新增 Skill。
